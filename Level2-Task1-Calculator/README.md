# MintCalc - Calculator

## About the Project

MintCalc is a simple calculator web application created as part of my Oasis Infobyte Web Development and Designing internship.

The project allows users to perform basic mathematical calculations using a clean mint green design.

## Features

- Separate Home page
- Separate Calculator page
- Separate Result page
- Separate About page
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Clear button
- Delete button
- Responsive design
- Mint green color theme

## Technologies Used

- HTML5
- CSS3
- JavaScript
