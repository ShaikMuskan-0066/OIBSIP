# Level 2 Task 2 - Tribute Page

## Project Name

Kalam Tribute Page

## About the Project

This project is a responsive tribute website dedicated to
Dr. A. P. J. Abdul Kalam.

The website presents his life, achievements and important
events through different navigation pages.

## Pages

- Home
- About
- Achievements
- Timeline

## Features

- Responsive design
- Navigation bar
- Multiple HTML pages
- Hero section
- Tribute content
- Achievement cards
- Life timeline
- Purple color theme
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click on the file.
4. Select "Open with Live Server".
