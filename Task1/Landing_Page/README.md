# GreenFlow - Landing Page

## About the Project

This is my **Level 1 Task 1** project for the **Oasis Infobyte Web Development and Designing Internship**.

I created a simple and responsive landing page for a fictional brand called **GreenFlow**. The idea behind the website is to promote smart and sustainable living.

I focused mainly on making the page clean, simple, and easy to use.

## Technologies Used

* HTML
* CSS

I used HTML to create the structure of the webpage and CSS to design the page and make it responsive.

## What I Included

The landing page contains:

* Navigation bar
* Hero section
* Main heading and description
* Call-to-action button
* Information sections
* Footer section
* Contact and social media placeholders
* Responsive layout for different screen sizes

## How to Run

To run this project:

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click on the file and select **Open with Live Server**.

The website will then open in the browser.

You can also simply open the `index.html` file directly in a browser.

As I was working on this project, I had some difficulty with making the layout look good on different screen sizes and keeping the spacing consistent.

I solved these issues by using CSS Flexbox, Grid, media queries, and proper spacing.
