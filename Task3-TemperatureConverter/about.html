About TempConvert

TempConvert is a simple web-based temperature conversion application created as part of the Oasis Infobyte Web Development and Designing internship.

The application allows users to convert temperatures between Celsius, Fahrenheit and Kelvin.

Technologies

HTML5
CSS3
JavaScript

Conversions

Celsius → Fahrenheit
Celsius → Kelvin
Fahrenheit → Celsius
Fahrenheit → Kelvin
Kelvin → Celsius
Kelvin → Fahrenheit

Features

Input validation
Absolute zero checking
Responsive design
