# Temperature Converter

## About the Project

This is a simple Temperature Converter web application created as part of my Oasis Infobyte Web Development and Designing internship.

The project allows users to convert temperatures between:

* Celsius
* Fahrenheit
* Kelvin

The project has separate pages for the Home page, Converter page, Result page and About page.

## Features

* Simple and clean user interface
* Separate Home page
* Separate Temperature Converter page
* Separate Result page
* Celsius, Fahrenheit and Kelvin conversion
* Input validation
* Absolute zero validation
* Responsive design
* Easy navigation between pages

## How It Works

1. Open the Home page.
2. Click **Start Converting**.
3. Enter a temperature.
4. Select Celsius, Fahrenheit or Kelvin.
5. Click **Convert Temperature**.
6. The application calculates the temperature.
7. The user is automatically taken to the Result page.
8. The Result page displays the Celsius, Fahrenheit and Kelvin values.

## Conversion Formulas

### Celsius to Fahrenheit

`°F = (°C × 9/5) + 32`

### Celsius to Kelvin

`K = °C + 273.15`

### Fahrenheit to Celsius

`°C = (°F − 32) × 5/9`

### Fahrenheit to Kelvin

`K = (°F − 32) × 5/9 + 273.15`

### Kelvin to Celsius

`°C = K − 273.15`

### Kelvin to Fahrenheit

`°F = (K − 273.15) × 9/5 + 32`

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The Home page will open in the browser.
6. Click **Start Converting** to use the application.
