# Level 2 - Task 4: Login Authentication System

## 📌 Project Overview

This project is a simple and responsive Login Authentication System developed as part of the Oasis Infobyte Web Development and Designing Internship.

The application allows users to create an account, log in using their registered credentials, access a protected dashboard, and log out securely from the current session.

## 🎯 Objective

The main objective of this project is to understand the basic concepts of user authentication and form validation using HTML, CSS, and JavaScript.

## ✨ Features

- User Registration
- User Login
- Email and password validation
- Password length validation
- Login error messages
- Protected dashboard
- Welcome message for logged-in users
- Logout functionality
- Responsive design
- Local storage for demonstration purposes
- Simple and professional user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
