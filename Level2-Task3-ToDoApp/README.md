# Level 2 Task 3 - To-Do Web App

## Project Name

TaskFlow - To-Do Web App

## About the Project

TaskFlow is a simple and responsive To-Do Web App
created to help users manage their daily tasks.

Users can add tasks, mark tasks as completed,
delete tasks and clear completed tasks.

## Pages

- Home
- Tasks
- About

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Total task counter
- Completed task counter
- Pending task counter
- Enter key support
- Responsive design
- Professional navy blue theme

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Right-click on the file.
4. Select "Open with Live Server".
5. Click the Tasks page in the navigation bar.
