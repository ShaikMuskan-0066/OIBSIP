About TaskFlow

TaskFlow is a simple and responsive To-Do Web App created to help users manage their daily tasks.

Users can add new tasks, mark tasks as completed, delete unwanted tasks, and clear all completed tasks.

The project uses HTML for structure, CSS for styling, and JavaScript for task management and interaction.

Easy to Use

Simple design and clear controls make task management easy.

Responsive Design

The application works on desktop, tablet and mobile screens.

Productivity Focused

Helps users organize their work and complete their goals.
